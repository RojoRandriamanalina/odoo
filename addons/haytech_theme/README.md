# Thème HayTech (Odoo 20)

Charte HayTech pour Odoo 20 : bleu nuit `#0F2747`, turquoise `#14B8A6`, Space Grotesk + Inter, logo, favicon,
page de connexion et couleurs des documents.

## Installation
1. Copier le dossier `haytech_theme` dans un dossier d'addons (ex. `/mnt/extra-addons`) ou dézipper l'archive dedans.
2. Redémarrer Odoo, puis Applications → Mettre à jour la liste des applications.
3. Installer « Thème HayTech » (ou `odoo -d <base> -i haytech_theme`).

Le module s'installe seul à la création d'une nouvelle base (`auto_install`). Polices sous licence OFL (voir `static/src/fonts`).
